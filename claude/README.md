# Claude layer (draft for Jeremiah)

`CHECKLIST.md` is the file to upload to a Claude project. It is the master list. The other files repeat one group of those checks and add before/after lines taken from the lessons.

This index is a draft. A file is mapped to a job only when a check's tag already names that job. Tags marked `unclear` are not assigned. `snipe` and `thread` never appear as formats to write. No lesson names the stage "drafting" or "flow edit," so those jobs have no file yet.

## Use this file when the tag already names the job

- Hook, headline, subject line, lead, first 10 lines, or an opening lede: `hooks.md`.
- Cadence, story pace, VSL delivery, projection flow, or long-form sales-letter ambience: `flow.md`. The causal-chain check tagged `stage: flow` is in `transitions.md`.
- CTA, P.S., guarantee, offer section, cart sequence, welcome email 1, or presale emails tagged PPLC, PLC1, PLC2, PLC3, and PLC4: `closes.md`.
- Liftnote subject-line-to-body, a section transition, or an upsell transition: `transitions.md`. The sales-letter order check names the vehicle and leaves the stage `unclear`, so it is not a job assignment.
- Liftnote first sentence ("you"): `pov-tense.md`. That file has no tense checks.
- Headline power words, including the high-end status words and the "skyrocket / unlock / elevate" ban: `word-choice.md`.
- Long-form story, short-form story, social post, or a sales-letter story used as hook, explanation, or proof: `stories.md`.

## Do not assign yet

- Drafting. Nothing is tagged drafting.
- A general flow edit. The lessons say cadence, pace, and flow. They do not say "flow edit."
- Most of `persuasion.md`, `pov-tense.md`, and `word-choice.md`. Those checks are tagged `unclear` on vehicle, stage, or both.
- Upsell quality, downsell, one-time discount, and cross-sell quality in `closes.md`. The vehicle is named. The stage is `unclear`.
- The advertorial "do not hard sell" check. The vehicle is named. The stage is `unclear`.
- VSL structure beyond delivery, and funnel math. Those lessons are not draft checks, or they name no review stage. See the pull request.

Please mark the `unclear` tags before this map is treated as final.
