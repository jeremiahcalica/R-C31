# Draft checklist

Yes/no checks for a draft, merged where lessons overlap. No rule was added from outside the two source files. `vehicle` and `stage` are `unclear` unless the lesson names them. Do not infer. The lessons never name `snipe` or `thread` as a format to write. Upload this file to a Claude project. Topic files add quoted before/after pairs.
